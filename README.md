# chuanhoadulieu — bản xuất bản của cổng từ điển AFP

**Toàn bộ repo này do máy ghi ra. Đừng sửa gì ở đây.** Lần xuất bản sau chạy
`rsync --delete`, mọi thay đổi sửa thẳng vào đây sẽ bị xoá mà không báo gì.

Bản gốc nằm ở `myafp/aBP`, thư mục `cong/site/`. Muốn sửa thì sửa bên đó rồi chạy:

```bash
bash cong/xuat-ban.sh
```
